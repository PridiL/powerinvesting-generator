Technical level rules
Values are ticks from the closing price — support and stop below, resistance above. Both pairs read outward from the close, so support shows higher/lower and resistance shows lower/higher. Tick size follows the SET spread table and is re-read at every step, so levels stay valid across a price band boundary.
